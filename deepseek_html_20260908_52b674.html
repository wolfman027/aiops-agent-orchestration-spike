🔄 核心工作流（最终版）

[日志报错] → [POST /diagnose] → 立即返回 { status: "analyzing" } │ ▼ 前端轮询 GET /status │ ├─ 全自动阶段（无人工介入） │ ├─ 1. 自主调用工具收集证据（diagnose_pod, query_logs, query_metrics） │ ├─ 2. 根因分析 │ └─ 3. 生成修复计划 → status 变更为 "pending_approval" │ ├─ 人工审批（/approve） │ ├─ 批准 → 后端执行修复 → ToolResultBlock(result=修复结果) 喂回 → status: "completed" │ └─ 驳回 + feedback → ToolResultBlock(result="驳回反馈: ...") 喂回 → reanalyze_count++ │ ├─ reanalyze_count < 3 → 重新分析 │ └─ reanalyze_count ≥ 3 → UserInterruptEvent + status: "closed_manual" │ └─ 异常 → status: "failed"

📊 完整状态机

analyzing → pending_approval → executing → completed │ │ ▼ ▼ failed rejected (驳回) │ │ ▼ ▼ │ analyzing (重新分析, reanalyze_count++) │ │ ▼ ▼ │ reanalyze_count ≥ 3 → closed_manual ▼ (人工介入)
  • analyzing：Agent 正在调查分析（前端轮询等待）
  • pending_approval：等待人工审批修复计划
  • executing：审批通过，正在执行修复
  • completed：流程结束，成功
  • failed：模型 API 报错或工具异常，需人工介入
  • closed_manual：驳回 ≥3 次强制关单，需人工处理

✅ 人工审批机制（核心修正）

❌ 错误写法（v2 伪代码，官方 API 不支持）
agent.reply(ConfirmResult(approved=False, feedback="内存限制建议调大"))

ConfirmResult 没有 feedback 参数，且 v2 把 "external tool" 和 "RequireUserConfirmEvent" 两种机制混写了。

✅ 正确写法：统一走 external tool + ToolResultBlock
# 1. 工具定义（以官方示例为准） @tool(requires_confirmation=True) # 参数名以官方文档为准！ def execute_fix_plan(fix_steps: str, session_id: str) -> str: """执行修复计划（需人工审批）""" # 实际修复逻辑 return f"修复已执行: {fix_steps}" # 2. /approve 实现 @app.post("/approve/{session_id}") async def approve(session_id: str, approved: bool, feedback: str = ""): agent = agents.get(session_id) if not agent: return {"error": "session not found"} if approved: # 批准：后端执行修复，结果作为 ToolResult 喂回 result = execute_real_fix(sessions[session_id]["plan"]) agent.reply(ToolResultBlock(result=result, is_error=False)) sessions[session_id]["status"] = "executing" else: # 驳回：feedback 文本直接作为 ToolResult 喂回（注意：is_error=False） agent.reply(ToolResultBlock( result=f"驳回反馈: {feedback}，请根据反馈重新分析", is_error=False # ⚠️ 不是 error，让 LLM 读到反馈自然重新分析 )) sessions[session_id]["reanalyze_count"] += 1 sessions[session_id]["status"] = "analyzing" return {"status": sessions[session_id]["status"]}

关键点：驳回时 不要用 is_error=True，否则 LLM 会当系统错误而非用户反馈。

📡 API 接口设计（修正 /diagnose 响应）

POST /diagnose

请求

{ "error_log": "payment-service Pod 频繁重启，状态 CrashLoopBackOff", "session_id": "可选" }

响应（立即返回）

{ "session_id": "uuid-xxx", "status": "analyzing", "message": "诊断任务已启动，请轮询 /status 获取进展" }

⚠️ 注意：提交瞬间 没有 plan_summary，status 是 analyzing 不是 pending_approval。

GET /status/{session_id}

响应（轮询）

{ "status": "pending_approval", "plan": "完整的修复计划内容（仅当 status=pending_approval 时存在）", "reanalyze_count": 0, "created_at": "2026-09-08T10:00:00Z" }

前端应轮询 /status 直到 status 变为 pending_approval、completed 或 failed。

POST /approve/{session_id}

请求

{ "approved": true, "feedback": "驳回时必填，提供修改建议" }

响应

{ "status": "executing" | "completed" | "analyzing" | "closed_manual" | "failed", "message": "..." }

🔒 强制关单与挂起清理（修正 #3）

问题：驳回 ≥3 次关单时，Agent 还停在挂起状态，需发送 UserInterruptEvent 收尾，否则状态不一致 + 内存泄漏。
# 在 /approve 或后台任务中 if sessions[session_id]["reanalyze_count"] >= 3: # 1. 标记状态 sessions[session_id]["status"] = "closed_manual" sessions[session_id]["closed_reason"] = "驳回次数 ≥ 3，人工介入" # 2. 清理挂起的 Agent agent = agents.pop(session_id, None) # 从内存 dict 移除 if agent: # 发送中断事件，让 Agent 优雅退出（可选） agent.emit(UserInterruptEvent(reason="驳回次数超限，强制关单")) # 或直接清理引用，Python GC 会回收 # 3. 返回结果 return { "status": "closed_manual", "message": "已强制关单，请人工处理", "reanalyze_count": sessions[session_id]["reanalyze_count"] }

⏰ 会话过期与内存管理（修正 #4）

问题：内存 dict 不清理会无限涨。completed 会话需自动过期，failed 状态需明确处理。
import time from collections import defaultdict class SessionStore: def __init__(self, ttl_seconds=3600): # 1小时过期 self._sessions = {} self._ttl = ttl_seconds def set(self, sid, data): self._sessions[sid] = { "data": data, "expires_at": time.time() + self._ttl } def get(self, sid): entry = self._sessions.get(sid) if entry and entry["expires_at"] > time.time(): return entry["data"] # 过期则清理（含对应的 agent 实例） if sid in agents: agent = agents.pop(sid) # 可选：发送中断事件 agent.emit(UserInterruptEvent(reason="会话过期")) self._sessions.pop(sid, None) return None def cleanup(self): """定时清理过期会话""" now = time.time() expired = [sid for sid, entry in self._sessions.items() if entry["expires_at"] <= now] for sid in expired: if sid in agents: agents.pop(sid, None) self._sessions.pop(sid, None) return len(expired)
